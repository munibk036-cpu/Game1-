RAYAN'S 3D CAR RACING GAME

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome or Microsoft Edge.
3. Keep an internet connection active because the Three.js 3D library loads from a CDN.

Controls:
- Left / Right arrow keys or A / D: steer
- Up arrow or W: accelerate
- Down arrow or S: brake
- C: switch between third-person and first-person camera
- Space: pause/resume
- On-screen buttons also work with mouse or touch.

Features:
- 3D road and environment
- Player car and traffic cars
- Steering, speed-up and brake buttons
- Speedometer and score
- Two camera views
- Restart button and collision detection

Note:
This is a starter game project. You can expand it with new tracks, sounds, menus, and car models.
